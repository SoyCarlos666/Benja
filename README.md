# BNJXS__ — Manager Portfolio

Portafolio web profesional para GitHub Pages o Netlify.

## Archivos
- `index.html`
- `style.css`
- `script.js`
- `config.js`

## Editar información
Abre `config.js` y modifica nombre, logo, contacto, proyectos, habilidades y reseñas.

## Publicar en GitHub Pages
Sube los cuatro archivos a la raíz del repositorio y activa GitHub Pages desde Settings → Pages.
